A Hytale mod that I'm making to learn Hytale modding.

Currently includes:
A workbench for making items from the mod.
2 Furnaces.
A Grinder to double ores.
A Generator for producing power.
Cables for power transport.
Tin Ore and Processing.
Rubber Trees (When V2 is released)

- Hytalor is required for all other world gen. (Currently Disabled)
